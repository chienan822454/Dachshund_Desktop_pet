旺旺（臘腸狗桌寵）無法啟動時的解決方法
==========================================

■ 黑色視窗出現「Windows marks DachshundPet.ps1 as "downloaded from the internet"」

  原因：從 GitHub 下載的 ZIP（或 Email、Teams、瀏覽器下載的檔案），Windows 會標記成「從網路下載」。
        為了安全，旺旺的啟動檔不會執行這種檔案，也不會自己偷偷解除。
        確定檔案是你自己下載的，就可以手動解除封鎖（只要做一次）：

  方法一（最快，不用重新下載）
    1. 關掉黑色視窗。
    2. 在旺旺資料夾裡的「DachshundPet.ps1」按右鍵 →「內容」。
    3. 在「一般」分頁最下面的「安全性」，勾選「解除封鎖」→ 按「確定」。
    4. 再雙擊 START_Dachshund.cmd。
       只有 DachshundPet.ps1 這一個檔案需要解除封鎖，圖片和聲音不用。
       如果 Windows 問「要執行這個檔案嗎？」，按「執行」；
       也可以用同樣的方法把 START_Dachshund.cmd 解除封鎖，以後就不會再問。

  方法二（整個資料夾一次解除）
    1. 刪掉剛剛解壓縮出來的資料夾。
    2. 在下載的 ZIP 檔按右鍵 →「內容」→ 勾選「解除封鎖」→「確定」。
    3. 在 ZIP 檔按右鍵 →「全部解壓縮」，再雙擊 START_Dachshund.cmd。

  找不到「解除封鎖」？
    表示這台電腦（通常是公司電腦）不允許自己解除封鎖，旺旺不會繞過這個保護。
    請改用 OneDrive 同步到這台電腦的旺旺資料夾，或用隨身碟從原本那台電腦的旺旺資料夾複製過來，
    或請 IT 協助。

■ 黑色視窗出現「set to block unsigned scripts」
  這台電腦設定成只能執行簽署過的指令碼。旺旺不會改這個設定；公司電腦請洽 IT。

■ 黑色視窗出現「locked down by device management」
  公司的裝置管理限制了 PowerShell。旺旺不會繞過；請洽 IT。

■ 其他狀況
  雙擊 DIAG_Dachshund.cmd，把黑色視窗的畫面截圖給我。
  旺旺出現後當掉的話，資料夾裡會有 DachshundPet_Error_ 開頭的文字檔，也一起給我。
