臘腸狗桌寵　V1.29.0（低風險版）—— 旺旺
由 Fighter V24.7 精簡而來：只保留臘腸狗；格鬥家、中英翻譯和英文練習都已移除。

【V1.29.0 新功能：飛行特技、彩帶留言、飛行速度】
- 飛行特技：飛行模式中，旺旺飛到一個地方後偶爾會表演：翻一圈筋斗，或衝高高再俯衝下來。
- 飛機彩帶留言：右鍵 →「飛機彩帶留言…」寫一句話（最多 20 個字），開飛機時飛機後面會用繩子拖著寫了這句話的彩帶，
  彩帶會隨風飄動；空白就不拖彩帶。這句話會記住，下次開旺旺還在。翻筋斗、降落滑行和停好時彩帶先收起來。
- 飛行速度：右鍵 →「飛行速度」→ 慢／一般／快。
- 飛行模式中叫旺旺做任何事（吃點心、喝水、丟肉乾、睡覺、上廁所、才藝、動作、番茄鐘…）：
  會先自動切換到重力模式，開飛機滑翔回工作列降落，停好 3 秒變回衣服後才去做那件事。
- 飛行模式幫你換上飛行員汪汪的話，關掉飛行模式（或改成重力模式）降落後，會換回原本穿的衣服。

【V1.28.0 新功能：旺旺開飛機、飛行模式】
- 穿「老式飛行員汪汪」又開著重力模式時，把旺旺往上丟（或甩出去、放開掉下來）：
  往下掉時身上會變出紙箱做的紅白雙翼飛機（像巡邏車汪汪一樣套在身上），螺旋槳轉起來，
  機頭微微朝下、一邊往前一邊慢慢滑翔下來；快到工作列時拉起機頭，輪子著地、滑行一小段停下來，
  停好 3 秒後把飛機收起來，變回飛行員裝。飛到螢幕邊邊會掉頭。高度太低時照舊直接掉下來。
- 右鍵 →「飛行模式（穿飛行員汪汪開飛機到處飛）」：旺旺開著飛機在整個螢幕上到處亂飛。
  沒穿飛行員汪汪時會自動換上。飛行中點右下角頭像或浮動按鈕叫牠，會直接飛到滑鼠旁邊；
  抓起來放開會從那裡繼續飛。再點一次「飛行模式」取消：飛到畫面下方找地方降落，停好 3 秒後變回飛行員裝。
- 飛行模式和重力模式不能同時開：勾選重力模式時會自動關掉飛行模式（旺旺會開著飛機滑翔回工作列）；
  勾選飛行模式時會自動關掉重力模式。
- 開飛機時有「噗噗噗」的螺旋槳聲，可在「互動設定 → 開飛機時發出螺旋槳聲」關掉。

【V1.26.1 修正：上廁所前先走一走、聞一聞】
- 旺旺要大便時（自己想大或從選單叫牠「上廁所」），不會再原地馬上蹲下：
  會先走到旁邊一段路找地方，途中停下來聞聞地上一兩次，找到地方後原地轉一圈、再蹲下來大便，像真的狗一樣。
- 找地方時會避開之前的大便；被叫過來、躲起來或睡覺時就不找了。走太久還找不到的話就在當下的地方大。

【V1.25.1 修正：叫旺旺時用跑的過來】
- 點右下角的旺旺圖示、浮動按鈕或「叫旺旺過來」時，旺旺沒有被視窗擋住的話，會從原來的地方一蹦一蹦地跑到滑鼠旁邊，
  到了再開心地跳一下，不再一下子就出現在滑鼠旁邊。穿警察巡邏車汪汪時一路閃燈、鳴笛。
- 被視窗擋住或躲在視窗後面時，照舊先打破螢幕衝出來，再跑過去。
- 滑鼠在另一個螢幕上時，旺旺還是直接出現在滑鼠旁邊（跑不過去）；番茄鐘專心時間也一樣。

【V1.25.0 新功能：大便和清潔、心情、早安午餐下班、旺旺的小聲音】
- 大便：旺旺大約每 1～2.5 小時會找個地方蹲下來大便（吃完點心或肉乾後 30～50 分鐘比較容易），
  在牠屁股後面留下一坨可愛的小大便。右鍵 →「叫旺旺做動作」→「上廁所（大便）」也可以叫牠去大（牠會先走一段路、聞一聞再蹲下）。
  ‧清潔：右鍵 →「清潔（拿掃把掃大便）」，滑鼠會變成掃把，點一下大便就會掃掉（閃一下亮晶晶）。
    掃把拿著時其他地方點不到，按右鍵或 Esc 結束；全部掃完或 45 秒沒動作也會自動收起來。
  ‧超過 10 分鐘沒清，大便上面會冒臭味線，還有三隻蒼蠅飛來飛去。
  ‧旺旺會離自己的大便遠遠的：站在大便旁邊會走開（有時候說「好臭～」），散步也不會走過去。
  ‧最多同時 3 坨；已經有 3 坨時，旺旺會忍著叫你快清。旺旺躲起來或躲到視窗後面時，大便也一起藏起來。
  ‧不想要：右鍵 → 互動設定 → 取消勾選「旺旺會隨地大便」。
  ‧蹲下來的圖目前只有不穿衣服的旺旺；穿衣服時先用坐下的姿勢，各件衣服的圖之後陸續補上。
- 心情：右鍵選單裡的「旺旺的心情：♥♥♥♡♡」。摸摸牠、餵點心、餵水、丟肉乾、表演才藝、清大便都會讓牠更開心；
  很久沒理牠會慢慢變低。心情超好時散步常常走到你的滑鼠附近；心情很低又一直沒人理，牠會背對你趴著鬧彆扭（「哼…」），
  摸摸牠或餵牠就會原諒你。心情記在 %APPDATA%\DachshundPet\mood.txt，關掉再開也記得。
- 一天的時間：早上第一次開旺旺（6～11 點）會伸懶腰說早安；12:00～12:30 會跑過來提醒你吃午餐；
  週一到週五下班時間（預設 17:30）會跑過來坐好搖尾巴說「下班囉」。下班時間在 右鍵 → 互動設定 →「下班提醒」修改或關閉；
  三個都不要：取消勾選「早安、午餐、下班時間會來找你」。
- 旺旺的小聲音：吃點心和肉乾時「嚼嚼」、喝水時「舔舔」、睡著時小小的打呼聲（都很小聲）。
  不想要：右鍵 → 互動設定 → 取消勾選「旺旺的小聲音」。旺旺汪汪叫或鳴笛時會先停一下。

【V1.24.1 修正：巡邏車汪汪一路鳴笛】
- 穿警察巡邏車汪汪跑起來時（追滑鼠、跑去吃肉乾、跑過來討吃的、被叫過來等），「喔咿喔咿」會一路響到停下來為止，
  不再只響一聲。停下來後大約半秒鐘鳴笛就停。
- 中間旺旺汪汪叫或打破螢幕時，鳴笛會先停一下，叫完再接著響。
- 不想要鳴笛聲：右鍵 → 互動設定 → 取消勾選「穿警察巡邏車汪汪跑起來時發出鳴笛聲」，之後只閃燈不出聲。

【V1.24.0 新功能：檢查更新】
- 右鍵 →「關於旺旺（版本號）」現在是一個小選單：
  ‧旺旺介紹…：原本的說明視窗。
  ‧檢查更新：旺旺去 GitHub 看有沒有新版本。有的話會告訴你版本和要下載多少，問你要不要下載；
    下載時旺旺照常陪你，下載好再問你要不要更新。按「是」旺旺會先關掉，換好檔案後自己再開起來（大約幾秒鐘）。
  ‧自動檢查更新（一天一次，有新版會提醒你）：預設打開。開旺旺 30 秒後會檢查一次（距離上次超過一天才會檢查），
    有新版只會冒泡泡和右下角通知提醒你，不會自己下載或更新。不想要可以取消勾選。
- 更新只會下載新的或改過的檔案（每個檔案下載完都會核對跟 GitHub 上的一模一樣），只換旺旺自己的檔案，
  不會刪除資料夾裡的任何檔案，鬧鐘、生日和其他設定都會留著。下載的暫存檔在 %APPDATA%\DachshundPet\update。
- 連不上 GitHub（沒網路或公司防火牆擋住）時，旺旺會說連不上，原本的旺旺照常可以用。
- 放在 OneDrive 同步資料夾裡的旺旺：新版本通常 OneDrive 就會自己同步過來；檢查更新也可以用，兩個不會互相衝突。

【V1.13.0 更新：八個新互動】

   右鍵 → 健康提醒 可以改成 30／45 分鐘或關閉。你離開電腦、專心時間和晚上不會提醒。
6. 番茄鐘：右鍵 → 番茄鐘 → 專心 25 分鐘（休息 5 分鐘）或專心 50 分鐘（休息 10 分鐘）。
   專心時旺旺安靜趴著陪你，不叫也不亂走；時間到汪汪叫提醒你休息，休息結束再叫你一次，點旺旺一下就停。

8. 肚子餓：2 小時沒吃點心或 1.5 小時沒喝水，旺旺會走到游標旁邊討吃的；餵了會特別開心。

【怎麼啟動】
雙擊 START_Dachshund.cmd。
黑色視窗閃一下做安全檢查後，臘腸狗會出現在螢幕右下角，過幾秒開始在桌面上走動。
工作列上會多一個縮小的「旺旺（臘腸狗桌寵）」PowerShell 視窗，那就是程式本身。
要結束：在旺旺身上按右鍵 →「關閉旺旺」，或關掉工作列上那個視窗。
同一時間只會有一隻旺旺；重複啟動時會提示「旺旺已經在桌面上了」。

【牠自己會做的事】
- 站著時慢慢搖尾巴、輕輕呼吸。
- 在桌面上到處走：四隻腳交替踏步、尾巴跟著擺，往左走會轉身；走到一個地方會停 2～8 秒。
  追著滑鼠跑或走很快時，會一蹦一蹦地跑。
- 站著休息時，大約每 10 秒隨機做一個動作：歪頭、聞聞、甩甩頭、東張西望、坐下、伸懶腰、趴一下、打哈欠。
- 站著時每隔幾秒眨一下眼。
- 每隔一段時間汪汪叫並吐舌頭開心跳一下（預設 25 秒，可以關掉或改成 15／40 秒、隨機 10～60 秒；晚上不會叫）。
  勾選「汪汪叫時發出旺旺的叫聲」才會發出旺旺真正的叫聲（預設不出聲），有時叫兩聲、有時三聲或四聲。
- 大約 4～8 分鐘沒人理牠，會睡 1～2 分鐘（Zzz…）：先打個哈欠、原地轉兩下，再隨機趴著睡（下巴靠在前腳上）、側躺曬太陽、翻肚睡、攤平曬肚子、縮成一團或窩在狗窩，睡醒會伸懶腰。
- 晚上 10 點到早上 7 點：大約 1 分鐘沒人理牠就回狗窩睡覺，睡到早上 7 點說早安；這段時間午睡和「隨便睡」也都睡狗窩。
- 你離開電腦 5 分鐘：趴下等你（等 10 分鐘會睡著）；你回來動滑鼠或鍵盤時跳起來迎接你。
- 2 小時沒吃點心或 1.5 小時沒喝水：走到游標旁邊討吃的。
- 健康提醒（預設關閉）：打開後每 30／45／60 分鐘提醒你喝水、起來動一動。
- 過年、端午、中秋、萬聖節、聖誕節和你設定的生日：自動換上節日的衣服。

【跟牠互動】
- 左鍵點一下：摸摸牠，牠會吐舌頭開心跳一下、快速搖尾巴。
- 滑鼠碰到牠：歪頭看你（最多每 10 秒一次）。
- 游標停在牠身上 1.5 秒：摸摸頭，牠會吐舌頭笑（「好舒服～♥」）。
- 左鍵拖曳：把牠抱起來，四隻腳會在空中划（「汪！放旺旺下來～」）；放下後會甩甩身體，休息約 6 秒再走。可以拖到另一個螢幕。
- 牠睡著時點一下：叫醒牠。翻肚睡的時候點牠的肚子是「摸肚子」：牠會張開眼睛、吐舌頭開心地扭來扭去，
  然後繼續睡（點頭才會叫醒牠）。
- 雙擊：原地轉圈圈。
- 拖著快速放開：把牠甩出去，牠會滑一段、碰到螢幕邊緣彈回來，停下後甩甩身體。

- 重力模式（右鍵勾選）：只在工作列上走；抓起來放開會掉回工作列，甩出去會照重力拋出去再落地；
  往下掉的時候兩隻耳朵會像翅膀一樣飛起來。

【安全性】
1. 只連 GitHub、只在檢查更新時：平常不連網路；只有按「檢查更新」或打開「自動檢查更新」時，
   會連到 GitHub（旺旺放的地方）看有沒有新版本，下載旺旺自己的檔案。不會上傳任何東西。
2. 不隱藏：PowerShell 視窗只是縮小在工作列，看得到也關得掉。
3. 不繞過安全設定：
   - 啟動前會先檢查（只讀取，不修改）這台電腦的 PowerShell 設定。
   - 如果公司或你自己已設定「只允許簽署過的指令碼」或「不允許指令碼」，程式就不會執行，並說明原因。
   - 如果電腦沒有特別設定，只在這一次執行中使用 RemoteSigned：本機檔案可以執行，從網路下載的指令碼仍會被擋。
   - 不會修改電腦上的任何設定。
4. 不需要系統管理員權限、不安裝任何東西、不寫入登錄檔、不設定開機自動啟動。
5. 只有出錯時，才會在這個資料夾留下 DachshundPet_Error_*.txt 錯誤記錄（每次執行最多 5 個）。
   設定鬧鐘時，鬧鐘會記在 %APPDATA%\DachshundPet\alarms.txt（刪掉全部鬧鐘就刪掉）；設定生日時，生日記在
   %APPDATA%\DachshundPet\birthday.txt（清除生日就刪掉）；除此之外不寫入任何檔案。
   「你回來了」只讀取電腦多久沒有人操作（Windows 的閒置時間），不會記錄你按了哪些鍵或點了哪裡。
   鬧鐘和自動汪汪叫的叫聲用 Windows 內建的音效播放（sounds 資料夾裡的 wangwang_bark*.wav），不連網。
6. 平滑邊緣：啟動時用 Windows 內建的 .NET 編譯器在記憶體中準備顯示程式（只呼叫 Windows 的視窗繪圖功能），
   不連網、不改設定；不允許時自動改用原本的顯示方式。

【換電腦使用】
- 需要 Windows 10 或 11；不用安裝，整個資料夾放在哪裡都可以。
- 用 OneDrive 同步或隨身碟複製整個資料夾。
- 也可以從 GitHub 專案首頁（https://github.com/chienan822454/Dachshund_Desktop_pet，公開專案，不用登入）下載：按 Code → Download ZIP；下載後先在 ZIP 檔按右鍵 → 內容 → 勾選「解除封鎖」→ 確定，再全部解壓縮（做法見 README.md）。
- 用 Email、Teams 或瀏覽器下載的檔案，Windows 會標記成「從網路下載」，啟動檔會拒絕執行；ZIP 檔要先解除封鎖再解壓縮。
  已經解壓縮才發現的話，只要在 DachshundPet.ps1 按右鍵 → 內容 → 勾選「解除封鎖」→ 確定，再啟動一次即可。

【如果無法啟動】
黑色視窗會用英文說明原因，然後停在那裡等你按任意鍵：
- "set to block unsigned scripts"：這台電腦不允許執行未簽署的指令碼。本程式不會繞過；公司電腦請洽 IT。
- "downloaded from the internet"：在 DachshundPet.ps1 按右鍵 → 內容 → 勾選「解除封鎖」→ 確定，再啟動一次；
  也可以在 ZIP 檔的內容勾選「解除封鎖」後重新解壓縮，或使用 OneDrive 同步、隨身碟複製的資料夾。
  （這時記事本也會打開 docs\start_help.txt，裡面有一步一步的說明。）
- "locked down by device management"：公司裝置管理限制了 PowerShell，本程式不會繞過；請洽 IT。
如果臘腸狗出現後當掉，會跳出錯誤訊息，並在資料夾留下 DachshundPet_Error_*.txt。
如果臘腸狗沒出現、也沒有任何訊息：先試 START_Dachshund_Classic.cmd；還是不行就雙擊 DIAG_Dachshund.cmd，把畫面截圖給我即可。
