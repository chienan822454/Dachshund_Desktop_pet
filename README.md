# 旺旺 — 臘腸狗桌寵（Windows）

一隻會在 Windows 桌面上走來走去的臘腸狗「旺旺」：會搖尾巴、散步、一蹦一蹦地追著滑鼠跑、歪頭、聞聞、伸懶腰、趴下、睡午覺、吃點心、追著丟出去的肉乾跑過去吃、喝水、握手、翻肚，翻肚睡時摸摸肚子會開心地扭來扭去，滑鼠停在頭上會瞇眼享受摸頭，可以躲到所有視窗後面在背景走動，叫牠時會在被擋住的地方打破螢幕衝出來，再跑到滑鼠旁邊，還能當鬧鐘和番茄鐘、提醒你喝水和起來動一動，也可以換 32 件衣服（日常衣服、節日衣服和造型扮裝）。

## 在另一台電腦下載並執行

1. 打開這個專案的 GitHub 首頁：https://github.com/chienan822454/Dachshund_Desktop_pet （公開專案，不用登入就能下載）。
2. 按綠色的 **Code** 按鈕 → **Download ZIP**。這裡永遠是最新版。
3. **先解除封鎖再解壓縮**：在下載的 ZIP 檔按右鍵 → **內容** → 勾選下方的 **解除封鎖** → **確定**。
   從瀏覽器下載的檔案會被 Windows 標記成「從網路下載」，沒有解除封鎖的話，啟動檔會拒絕執行。
   如果內容裡沒有「解除封鎖」（公司電腦可能不允許），請改用 OneDrive 同步的資料夾。
4. 在 ZIP 檔按右鍵 → **全部解壓縮**，打開解壓縮出來的 `Dachshund_Desktop_pet-main` 資料夾，雙擊 `START_Dachshund.cmd`。
5. 之後有新版本時，再下載一次 ZIP，用同樣的方式解壓縮即可。

> **已經解壓縮了才看到「[Cannot start] Windows marks DachshundPet.ps1 as "downloaded from the internet"」？**  
> 不用重新下載：在資料夾裡的 `DachshundPet.ps1` 按右鍵 → **內容** → 勾選最下面的 **解除封鎖** → **確定**，再雙擊 `START_Dachshund.cmd` 就可以了（只有這一個檔案需要解除封鎖）。黑色視窗也會用記事本打開中文說明 `docs/start_help.txt`。

> **關於檔案的更新日期**：每次出新版本時，只會更新有改到的檔案。所以 GitHub 上有些檔案旁邊顯示的是比較早的版本或日期，這是正常的：**那些檔案仍然是目前版本必要的一部分，請不要刪除**。下載時請一定用 **Code → Download ZIP** 下載整個專案。

需求：Windows 10 或 11（內建的 Windows PowerShell 5.1）。不用安裝、不需要系統管理員權限。

## 怎麼玩

- **左鍵點一下**：摸摸旺旺，牠會吐舌頭開心跳一下、快速搖尾巴；牠睡著時點一下會叫醒牠。翻肚睡時點牠的**肚子**是摸肚子：牠會吐舌頭開心地扭來扭去，然後繼續睡（點頭才會叫醒牠）。
- **左鍵拖曳**：把旺旺抱起來，放下後牠會甩甩身體。
- **雙擊**：旺旺原地轉圈圈，再開心跳一下。
- **拖著快速放開**：把旺旺甩出去，牠會滑一段、碰到螢幕邊緣彈回來，停下後甩甩身體。
- **滑鼠在牠面前快速左右晃**：逗牠玩，牠會歪頭盯著看、壓低身體，然後撲過來。
- **滑鼠一直繞圈圈**（同一個方向轉兩圈以上）：旺旺會跑過來追，追到就跟著一起轉圈圈。
- **重力模式**（右鍵勾選）：旺旺只在螢幕下方的工作列上面走；抓起來放開會掉回工作列，甩出去會照重力拋出去、落地彈一下再滑停；往下掉的時候兩隻耳朵會像翅膀一樣飛起來。
- **右下角的旺旺頭像**：旺旺一啟動就一直在右下角工作列（時鐘旁邊）。找不到旺旺時（跑到視窗後面、走到別的地方）點一下頭像，牠就會跑到滑鼠旁邊、出現在最前面；被視窗擋住時，螢幕會出現裂痕、玻璃碎開，旺旺從洞裡衝出來（右鍵 → 互動設定可以關掉）。頭像被收在「^」裡時，把它拖到工作列上就會一直顯示。
- **狗窩在左下角**：晚上睡覺或叫牠「窩在狗窩」時，旺旺會先走到螢幕左下角再窩進狗窩睡。
- **滑鼠移到旺旺身上**：游標會變成撫摸的手。
- **浮動按鈕**：螢幕上一個小小的旺旺頭像按鈕（就是 wangwang.ico），永遠在最上面。右鍵點它就是旺旺的選單，左鍵點它叫旺旺過來，按住可以拖到別的地方（右鍵選單可以開關，會記住位置）。
- **滑鼠停在頭上**：旺旺會閉上眼睛享受摸頭，慢慢搖尾巴（右鍵 → 互動設定可以關掉）。
- **離開電腦 5 分鐘**：旺旺趴下等你（等太久會睡著）；你一回來動滑鼠或鍵盤，牠就跳起來迎接你。
- **太久沒餵**：2 小時沒吃點心或 1.5 小時沒喝水，旺旺會走到游標旁邊討吃的；餵了會特別開心。
- **節日**：過年、端午、中秋、萬聖節、聖誕節和你設定的生日，旺旺會自動換上節日的衣服，過了再換回來。
- **右鍵選單**（V1.30.0 起分組：第一層是心情、餵點心、丟肉乾、換衣服、睡覺、飛行模式，其他在「照顧旺旺／動作和才藝／走動與飛行／先躲起來／時間小幫手／設定」裡；叫醒、停止鬧鐘叫聲、降落只在用得到時出現）：
  - 叫旺旺做動作（歪頭、聞聞、甩甩頭、東張西望、伸懶腰、趴一下、坐下、打哈欠）
  - 才藝表演（握手、轉圈、翻肚、坐下、趴下）：握手時點牠一下就是握到手了，翻肚時點牠一下牠會馬上跳起來
  - 餵點心（旺旺吃碗裡的點心）、丟肉乾（游標變成手捏著肉乾，旺旺追著跑，追到就搶走；點一下左鍵順著滑鼠方向丟出去，旺旺跑過去吃；每件衣服都可以）、餵水（碗裡換成水，旺旺伸舌頭舔水喝；每件衣服都可以）
  - 睡覺（趴著睡、側躺曬太陽、翻肚睡、攤平曬肚子、縮成一團、窩在狗窩）、叫醒旺旺
  - 換衣服：不穿衣服，以及三個分類（每件名稱後面有一小塊布料色塊；有帽子或頭飾的衣服睡覺時不戴）
    - 日常衣服：藍色小熊衣、HAPPY 恐龍衣、紅色鋪棉背心、迷彩鋪棉外套、軍綠鋪棉背心、學院風針織背心（酒紅／墨綠／淺灰／焦糖）、黃色小雨衣
    - 節日衣服：過年紅色唐裝、端午節粽子裝、中秋節小兔子裝、萬聖節小巫師裝、聖誕老公公裝、生日派對裝
    - 造型扮裝：小蜜蜂裝、熱狗堡裝、珍珠奶茶裝、小獅子裝、恐龍連帽裝、警察汪汪、警察巡邏車汪汪（跑起來警示燈閃爍、一路鳴笛，可在互動設定關掉鳴笛；坐下、握手、趴下和睡覺時把車停在後面）、消防員汪汪、鯊魚汪汪、機房工程師汪汪、醫生汪汪、太空人汪汪、廚師汪汪、冬天毛衣圍巾汪汪、小籠包汪汪、老式飛行員汪汪（坐下、握手、趴下和睡覺時後面停著老式螺旋槳飛機）
  - 先躲起來（躲到所有視窗後面，在背景照樣走動：15 分鐘／30 分鐘／1 小時／直到叫牠出來；時間到或點右下角頭像、浮動按鈕叫牠時，會在被擋住的地方打破螢幕衝出來，再跑到滑鼠旁邊）
  - 鬧鐘：可以設定好幾組（最多 20 組），每組有自己的提醒文字，選「只響一次」或「每天」；只響一次的鬧鐘響完會自動關閉，但設定會留著，下次打勾就能再用。在鬧鐘設定視窗裡按「修改」或點時間可以修改，按垃圾桶圖示再確認一次就會刪除；右鍵選單裡點一下鬧鐘就能開啟或關閉，也可以從「修改鬧鐘」「刪除鬧鐘」直接選要改或要刪的那一組。時間到旺旺會跑出來，用旺旺真正的叫聲汪汪叫，點牠一下就停；也有 5／10／30 分鐘、1 小時後叫我的倒數，和「聽聽旺旺的叫聲」
  - 番茄鐘：專心 25 分鐘（休息 5 分鐘）或專心 50 分鐘（休息 10 分鐘）；專心時旺旺安靜趴著陪你，時間到汪汪叫提醒你休息
  - 健康提醒：每 30／45／60 分鐘提醒你喝水、起來動一動（預設關閉）
  - 自由走動、走動速度、追著滑鼠跑（走很快或追滑鼠時會一蹦一蹦地跑）、重力模式（只在工作列上走）、飛行模式（穿飛行員汪汪開飛機到處亂飛、偶爾翻筋斗或俯衝，跟重力模式只能開一個）、飛行速度（慢／一般／快）、飛機彩帶留言（飛機後面拖著你寫的一句話）、自動汪汪叫（間隔 15／25／40 秒或隨機 10～60 秒；勾選「汪汪叫時發出旺旺的叫聲」才會用旺旺真正的叫聲，預設不出聲，叫的時候有時兩聲、三聲或四聲）、午睡、晚上自動睡覺（晚上10點～早上7點，一定睡狗窩）、尺寸（迷你／小／一般／大／巨大）、平滑邊緣、關閉旺旺
  - 互動設定：離開電腦時等你、回來時迎接你／滑鼠在牠面前左右晃會撲過來／滑鼠一直繞圈圈會跑過來追／肚子餓、口渴會來討吃的／節日自動換衣服／從右下角叫旺旺時，被視窗擋住會打破螢幕衝出來／滑鼠停在頭上會瞇眼享受摸頭／穿警察巡邏車汪汪跑起來時發出鳴笛聲／旺旺會隨地大便／旺旺的小聲音／早安、午餐、下班時間會來找你／開飛機時發出螺旋槳聲／下班提醒時間／設定生日
  - 顯示浮動按鈕（右鍵開旺旺選單，不用點旺旺）
  - 關於旺旺（顯示版本號和簡單說明）

## 安全性

- 不安裝任何東西、不修改 Windows 設定、不需要系統管理員權限。
- 平常不連網路；只有「關於旺旺 → 檢查更新」或「自動檢查更新」（一天一次，可關掉）會連到這個 GitHub 下載旺旺自己的檔案：只下載新的或改過的檔案、每個都核對過，不會刪除任何檔案，也不會上傳任何東西。
- 打破螢幕的效果只是畫在旺旺自己的透明視窗上，判斷旺旺有沒有被擋住也只看視窗的位置，不會讀取或改動其他視窗。
- 平滑邊緣：啟動時用 Windows 內建的 .NET 編譯器在記憶體中準備顯示程式；不允許時自動改用原本的顯示方式。
- 不繞過 PowerShell 的安全設定：電腦設定成「只允許簽署過的指令碼」或「不允許指令碼」時，程式不會執行，並說明原因。
- 只有出錯時，才會在自己的資料夾留下 `DachshundPet_Error_*.txt` 錯誤紀錄。
- 設定鬧鐘時，鬧鐘會記在 `%APPDATA%\DachshundPet\alarms.txt`（重新開啟旺旺也記得；刪掉全部鬧鐘就刪掉這個檔案）。
- 鬧鐘和自動汪汪叫的叫聲是旺旺真正的叫聲（`sounds/wangwang_bark*.wav`），用 Windows 內建的音效播放。
- 浮動按鈕的開關和位置記在 `%APPDATA%\DachshundPet\dot.txt`。
- 設定生日時，生日記在 `%APPDATA%\DachshundPet\birthday.txt`（清除生日就刪掉這個檔案）。
- 「你回來了」只讀取電腦多久沒有人操作（Windows 的閒置時間），不會記錄你按了哪些鍵或點了哪裡。

## 無法啟動時

看不到旺旺時，先試 `START_Dachshund_Classic.cmd`。

雙擊 `DIAG_Dachshund.cmd`，黑色視窗會用英文說明原因並停住：

- `block unsigned scripts`：這台電腦不允許執行未簽署的指令碼（公司電腦請洽 IT）。
- `downloaded from the internet`：檔案是從網路下載的。在 `DachshundPet.ps1` 按右鍵 → 內容 → 勾選「解除封鎖」→ 確定，再啟動一次；或在 ZIP 檔解除封鎖後重新解壓縮，或改用 OneDrive 同步的資料夾。
- `locked down`：裝置管理限制了 PowerShell（請洽 IT）。
